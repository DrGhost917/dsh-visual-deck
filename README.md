# dsh-visual-deck

> DeepSeek Harness 的**启动动画**与**会话背景**管理器。
> 把本地的图片、视频导进素材库，视频可以设成开机动画，图片或视频可以铺成整个界面的背景。

## 它做什么

Harness 默认是干干净净的深色界面。这个插件给它加两层"皮肤"：

| | 是什么 | 素材类型 |
|---|---|---|
| **启动动画** | 页面加载时先铺满屏幕播一段片子，播完（或点击跳过）再淡出到界面 | 视频 |
| **会话背景** | 常驻在所有面板背后的一层图/视频，配合界面半透明，让壁纸透出来 | 图片或视频 |

素材全部来自你的本地文件，不联网、不上传、不经过任何第三方服务。文件存在 `~/.dsh/visual-deck/` 下，随时可以自己打开看、备份或删掉。

### 功能一览

- **素材库**：三列大图墙，视频自动用首帧当封面
- **三种导入方式**：点按钮 / 拖进面板 / `Ctrl+V` 直接粘贴（截图工具复制的图也能用）
- **启动动画**：带声音播放、音量可调、播放时机（每次启动 / 每天一次 / 仅首次）、随时预览
- **会话背景**：强度（面板透明度）、模糊（0–12 px）、临时开关
- **纠错**：图片永远设不成启动动画 —— 按钮置灰、宿主拒绝、运行时再判一次，三道闸

## 安装

> 要求：DeepSeek Harness 0.2.x（desktop 或 web profile 均可）。

### 方式 A：从 npm 安装（推荐）

```bash
dsh plugin --profile desktop add dsh-visual-deck
```

装完在设置里能找到「启动动画与背景」这一页。如果没出现，检查 `profiles/<你的 profile>/package.json` 的 `dsh.profile.bundles` 里有没有 `dsh-visual-deck`。

### 方式 B：从本地 tgz 安装

```bash
dsh plugin --profile desktop add ./dsh-visual-deck-0.2.0.tgz
```

### 方式 C：开发模式（软链接，改代码即时生效）

```bash
dsh plugin --profile desktop add link:/path/to/dsh-visual-deck
```

> 宿主侧（`index.js`）改了要**重启应用**才生效 —— 模块是启动时加载的。
> 客户端（`client.js`）与注入的运行时（`runtime/`）刷新页面即可。

## 第一次使用

1. 打开 **设置 → 启动动画与背景**
2. 点第一格「**拖到这里 / 或点击选择文件**」，选一个视频或图片
3. 选中素材 → 点「**设为会话背景**」，背景立刻出现
4. 想让它当开场动画：选中视频 → 点「**设为启动动画**」→ 刷新页面看效果

背景生效后，界面面板会变成半透明。觉得字看不清就往左推「背景强度」，觉得太糊就调「背景模糊」。

## 功能详解

### 素材库

- 每格下方显示**文件名**与**类型 · 大小**
- 鼠标移到卡片上，底部浮出三个快捷操作：**启动 / 背景 / 删除**（键盘 Tab 也能聚焦）
- 右上角胶囊标记当前用途：`启动`、`背景`（同一个素材可以两样都是）
- 删除会先确认；如果它正在被用作背景或动画，会一并取消

### 启动动画

| 控件 | 说明 |
|---|---|
| 音量 | 0–100%，0 即静音。**背景视频永远静音**，这里是开场动画专用 |
| 播放时机 | `每次启动` / `每天一次` / `仅首次`。判断依据是宿主记录的"上次播放时间"，不依赖浏览器存储 |
| 预览启动动画 | 立刻用同一套覆盖层放一遍，无视上面的播放时机；点击画面 / 空格 / Esc 跳过 |

播放细节：最长 10 秒自动收场；鼠标点画面任意位置即跳过；被系统自动播放策略拦下时会自动退回静音重播。

### 会话背景

| 控件 | 说明 |
|---|---|
| 背景强度 | 0% = 界面接近原生（几乎看不见壁纸），100% = 面板最透、壁纸最清楚 |
| 背景模糊 | 0–12 px，拖大时图片层会自动放大 4% 避免边缘透明 |
| 显示壁纸 | 临时开关。关掉后界面立刻回到原生外观，**只影响这一页**，不动设置 |

亮色主题在同强度下会自动更实一些 —— 深色文字压在薄白面上对比度会掉，这不是随手定的值。

## 数据存放在哪

```
~/.dsh/visual-deck/
├── deck.json          # 清单：素材列表 + 当前设置
└── media/             # 素材文件本体（<uuid>.<ext>）
```

`deck.json` 长这样：

```json
{
  "version": 1,
  "items": [
    { "id": "…", "file": "….mp4", "name": "开场.mp4", "kind": "video",
      "ext": ".mp4", "mime": "video/mp4", "size": 208377344, "createdAt": 1792511684680 }
  ],
  "settings": {
    "backgroundId": "…",
    "bootId": "…",
    "bootVolume": 1,
    "backgroundStrength": 0.75,
    "backgroundBlur": 0,
    "bootWhen": "always",
    "bootShownAt": 1792512000000
  }
}
```

设置页右上角的「素材配置」可以只读查看它。直接改文件再刷新页面同样有效（写坏了会退回空清单，不会崩）。

## HTTP 接口

宿主在本地 HTTP 服务上挂了这些路由（仅本机、不需要 token，与 Harness 的页面同源）：

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/visual-deck/api/state` | 素材列表 + 当前设置 |
| POST | `/visual-deck/api/upload?name=<文件名>&kind=video\|image` | 原始字节上传，上限 200 MB |
| POST | `/visual-deck/api/settings` | `{backgroundId}` / `{bootId}` / `{bootVolume}` / `{backgroundStrength}` / `{backgroundBlur}` / `{bootWhen}` |
| DELETE | `/visual-deck/api/item?id=<id>` | 删除素材并清掉引用 |
| GET | `/visual-deck/media?id=<id>` | 媒体流（支持 Range，视频 seek 靠它） |
| POST | `/visual-deck/api/boot-shown` | 运行时打卡"这次开场放过了" |
| POST | `/visual-deck/api/client-report` | 界面诊断回执（排查"背景看不到"用） |

启动动画的"只接受视频"在宿主侧同样强制：`{bootId: <图片 id>}` 会返回 `400 boot-must-be-video`。

## 实现要点

给想改这个插件的人留几条踩过的坑：

1. **视觉层走索引注入，不走 React**。宿主的 `webserver/index-inject` 会在每次渲染首页时收集注入行，插件推一行 `<style>` + 一行 `<script>`，由脚本在应用挂载前挂上覆盖层和背景层。好处是不会和 React 渲染顺序打架，坏处是**改这段代码要刷新甚至重启**。

2. **页面在 `dsh-app://` 下，不是 `http://`**。桌面壳用自定义协议加载页面，所以页面里访问宿主接口**必须用相对地址**（`/visual-deck/...`）—— 用 `http://127.0.0.1:端口` 的绝对地址会变成跨域，被浏览器直接拦掉。

3. **只改主题 token，不改组件类名**。界面半透明通过覆写 `--dsw-alias-bg-*`、`--dsw-specific-sidebar-fill` 实现，一次改到所有面板，不依赖任何组件类名。

4. **弹层出现时必须恢复不透明**。设置、选模型这些模态也引用同一批 token，半透明会让背后的对话文字透上来叠成一片。运行时用 `MutationObserver` 检测"真正显示出来的弹层"，出现就把表面拉到接近不透明。

5. **别拿 `--dsw-alias-bg-base` 当文字色**。壁纸生效时它本身被改成了半透明，拿它当按钮文字色就是"白底近乎透明的字"。

6. **启动动画的播放时机要记在宿主**。`dsh-app://` 下 Web Storage 不一定可用，所以"上次播过没有"由宿主记在 `deck.json` 的 `bootShownAt`。

## 已知限制

- **文件上限 200 MB**，超过会弹窗提示（宿主侧同样拒绝）。
- **编码依赖 Electron 的构建**：H.264/AAC 的 mp4 一般没问题；HEVC、AV1 在部分构建上放不出来，表现为黑屏。建议用 H.264。
- **背景视频永远静音**：这是浏览器自动播放策略的硬要求，也是壁纸该有的行为。
- **启动动画是整页覆盖层**：只在页面加载时出现；改完设置要看效果请刷新页面（或用「预览」按钮）。
- **`prefers-reduced-motion`**：系统开了"减少动态效果"时不自动播动画、不播视频背景，但预览按钮仍然可用。
- 仅支持带 Web 界面的 profile（desktop / web）。

## 卸载

```bash
dsh plugin --profile desktop remove dsh-visual-deck
```

素材文件不会自动删除，需要的话手动删掉 `~/.dsh/visual-deck/`。
